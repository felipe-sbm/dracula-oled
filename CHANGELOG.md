# Changelog

All notable changes to the Dracula OLED theme will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2025-12-06

### Added
- Initial release of Dracula OLED theme
- True black backgrounds (`#000000`) optimized for OLED/AMOLED displays
- Complete Dracula color palette with vibrant accent colors
- Professional UI styling for all VS Code interface elements
- Full terminal ANSI color support
- Terminal styling with Dracula colors
- Git decoration colors (modified, deleted, untracked, conflicted)
- Editor features:
  - Line number styling
  - Bracket matching
  - Error and warning indicators
  - Selection and highlight colors
  - Find match highlighting
- Status bar customization with pink background and purple remote indicator
- Activity bar and sidebar dark theme
- Syntax highlighting for multiple languages:
  - JavaScript/TypeScript
  - JSON (with multi-level key coloring)
  - Markdown
  - HTML/CSS
  - PHP
  - Python
  - And more...

### Features
- Optimized contrast ratios for accessibility
- Reduced eye strain with true black backgrounds
- Power-efficient rendering on OLED displays
- Consistent color scheme across all UI elements
- Professional and clean aesthetic

### Color Palette
- **Background**: `#000000` (True Black)
- **Foreground**: `#F8F8F2` (Off-white)
- **Keywords**: `#FF79C6` (Pink)
- **Functions**: `#50FA7B` (Green)
- **Strings**: `#F1FA8C` (Yellow)
- **Numbers**: `#BD93F9` (Purple)
- **Types**: `#8BE9FD` (Cyan)
- **Comments**: `#6272A4` (Gray)
- **Errors**: `#FF5555` (Red)
- **Warnings**: `#FFB86C` (Orange)

### Status Bar
- Background: Pink (`#FF79C6`)
- Remote indicator: Purple (`#BD93F9`)
- Hover effects with lighter accent colors
