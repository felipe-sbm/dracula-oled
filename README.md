# Dracula OLED

A refined VS Code theme optimized for OLED and AMOLED displays, bringing the elegant Dracula color palette to true black backgrounds.

## Overview

Dracula OLED is a premium theme for Visual Studio Code based on the classic Dracula theme, specifically enhanced for developers using OLED and AMOLED screens. The theme delivers exceptional visual comfort by leveraging true black backgrounds (pure `#000000`), making it ideal for low-light environments and maximizing the benefits of modern display technologies.

With its vibrant, carefully-crafted color palette and dark aesthetic, Dracula OLED provides superior contrast and reduced eye strain during extended coding sessions.

## Features

- **True Black Backgrounds**: Optimized for OLED/AMOLED displays with pure black (`#000000`) backgrounds
- **Dracula Color Palette**: Maintains the iconic Dracula color scheme with vibrant, carefully selected hues
- **Professional UI**: Clean and consistent styling across all VS Code interface elements
- **Terminal Support**: Full ANSI color support with Dracula-themed terminal colors
- **Accessibility**: High contrast ratios ensure excellent readability

## Color Palette

| Color | Hex | Usage |

## Installation

1. Open VS Code
2. Go to **Extensions** (`Cmd+Shift+X` on macOS)
3. Search for "Dracula OLED"
4. Click **Install**
5. Select **Dracula OLED** from **Preferences > Color Theme**

Alternatively, set it in your `settings.json`:

```json
{
  "workbench.colorTheme": "Dracula OLED"
}
```

## Usage Tips

- **For OLED Displays**: This theme is specifically optimized for OLED/AMOLED screens to maximize contrast and minimize power consumption
- **Low Light Environments**: The true black background reduces eye strain in dark settings
- **Customization**: Modify the theme colors in VS Code's settings if you prefer different accent colors

## Recommended Settings

For the best experience, consider these VS Code settings:

```json
{
  "workbench.colorTheme": "Dracula OLED",
  "editor.fontLigatures": true,
  "editor.fontSize": 14,
  "editor.lineHeight": 1.6
}
```
